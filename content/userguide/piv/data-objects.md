Besides certificates, the PIV applet stores a number of standard data objects. The table below lists each object with its tag and capacity.

| Tag | Data object | Capacity |
|:----|:------------|---------:|
| `5FC102` | Card Holder Unique Identifier (CHUID) | 2916 bytes |
| `5FC107` | Card Capability Container | 287 bytes |
| `5FC109` | Printed Information | 245 bytes |

Certificate objects are described in [Certificates](certificates/).
